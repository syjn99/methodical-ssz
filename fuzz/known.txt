# Classes of differences that are recorded. One regular expression per line.
# A difference whose message matches a line skips the input.
# Set STRICT=1 to turn this filter off.
#
# Rule: one line for each tuple of fork, class, field name and exact limit,
# with any container and any nesting path. A field name with two limits gets
# two lines. A soft limit line takes any container only if Prysm's YAML makes
# that field name with that limit progressive in every Gloas container, and
# EthLib gives it no limit. Otherwise the line keeps the containers where it
# was seen. Value lines use the changed field name. Byte input lines keep
# their container families, because EthLib's message names no field.
# Risk: a wrong limit that equals a listed tag on a listed field name stays
# hidden, in any container.
#
# The soft limit lines and the panic lines come from Prysm's YAML and the struct
# tags (see those sections). When the Prysm pin changes, check them against the
# new YAML. Each other tuple comes from an input in testdata/fuzz/ or from a
# difference that a fuzz run found. Remove a line when its fix merges.
# A value input's message ends with "; changed: " and the fields it changed.
